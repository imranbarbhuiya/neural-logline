# Three-project roadmap

## 1. neural-logline

Ship a tiny local token classifier for plain-text log headers, with reproducible synthetic training, honest evaluation, and a dependency-free TypeScript runtime.

## 2. neural-formfield

Classify form controls from labels, accessible names, attributes, and nearby text. Return a constrained field type such as name, email, phone, address, company, or unknown. Evaluate with page-separated fixtures and never collect entered values.

## 3. neural-adselect

Classify candidate DOM containers as ad, sponsored content, newsletter, or normal content. Produce reversible cosmetic-rule suggestions, while standard filter lists and browser declarative rules handle network blocking. Begin in suggestion mode and measure false hides and page breakage on held-out sites.
